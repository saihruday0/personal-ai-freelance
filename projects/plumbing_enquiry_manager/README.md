# Plumbing Enquiry Manager

A Flask-based demo application for collecting and managing customer plumbing enquiries.

## Features

- Customer enquiry form
- Required-field validation
- Email format check
- SQLite database storage
- Business dashboard to view enquiries
- Enquiry status management:
  - New
  - Contacted
  - Completed

## Requirements

- Python 3
- Flask

## Setup

From the project root:

```powershell
python -m pip install -r projects/plumbing_enquiry_manager/requirements.txt
