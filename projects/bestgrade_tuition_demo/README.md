
# Bestgrade Tuition — Website Improvement Demo

## Project Overview

A standalone website improvement demonstration based on publicly visible information from Bestgrade Education.

## Objectives

- Improve the presentation of the FAQ section.
- Replace placeholder FAQ content with evidence-based answers.
- Organize existing tuition programme information.
- Improve navigation and responsive presentation.
- Create a professional, consistent visual identity.

## Pages

- `src/index.html` — Homepage
- `src/faq.html` — Frequently Asked Questions
- `src/pricing.html` — Programmes and Fees

## Technologies

- HTML5
- CSS3
- JavaScript

## Project Structure

- `src/` — Website source code
- `requirements/` — Project requirements
- `design/` — Design references
- `tests/` — Testing resources
- `reports/` — Project reports

## Validation

- Desktop layout manually checked.
- Mobile layout manually checked.
- Tablet layout manually checked.
- Navigation and internal links checked.
- FAQ accordion functionality checked.
- Pricing cards and layout checked.

## Important Notes

- This is an independent demonstration, not an official Bestgrade website.
- Programme information is based on publicly visible website content.
- Displayed prices have not been independently confirmed as current fees.
- No deployment or modifications to the original website have been made.

## Status

Demonstration developed and manually tested.
